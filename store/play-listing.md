## Full description
*(Play limit: 4000 characters)*

```
ApiWorkbench is an API client for building, sending and testing HTTP requests on your phone or tablet. No account, no ads, no analytics: it sends a request only when you ask it to, and only to the address you enter.

BUILD REQUESTS
• Every HTTP method, including the new QUERY method
• Query params, headers, and JSON, text, XML, form-urlencoded, multipart form-data, binary file and GraphQL bodies, with a JSON beautifier
• Bearer token, Basic and API key auth
• HTTP/1.1, HTTP/2 and HTTP/3 (QUIC)
• Accept self-signed certificates for local dev servers; set your own connect and response timeouts
• Request tabs: keep several requests open at once

ORGANISE
• Collections with folders
• Environments and collection variables: write {{baseUrl}} once and switch environments in one tap
• Dynamic variables such as {{$guid}}, {{$timestamp}} and {{$randomEmail}}
• History of your last 100 sends; reopen any of them

IMPORT AND SHARE
• Import Postman collections (v1, v2.0 and v2.1), environments, globals and full data exports. Folders, auth, variables and every body type carry over, and common test checks become Tests
• Import a request from a cURL command, or copy any request as one
• Export your workspace to a file and import it on another device
• Save a request and its response as a Markdown document, with auth tokens masked

TEST
• Assertions after every send: status code, body text, JSON fields (data.items[0].id), headers, response time
• Captures: save a token or an id from a response into a variable for the next request
• Collection runner: run a folder or a collection for up to 100 iterations, with a pass/fail list and latency stats
• Monitor mode re-runs requests every few seconds; data-driven runs take a JSON array of variable sets
• Load testing with up to 1,000 parallel users, by iterations, duration or until stopped, with live throughput and p50/p95/p99 latency. Save the call log as an HTML, CSV or JSON report

READ RESPONSES
• Status, latency and size at a glance
• Syntax-highlighted JSON, a raw view and a sortable headers table
• Copy any response

CHAOS MODE (OPTIONAL)
• A sound for each kind of status, confetti on success and a screen shake on errors. Import your own clips and map them to status codes

FITS YOUR SCREEN
• Phone layout with a navigation drawer and request and response tabs; wider screens get the side panel and a draggable splitter
• Help for every field, with an example: long-press to see it, and turn it off once you know your way around
• Teal light and dark themes, and Graphite

ApiWorkbench also runs on Windows, Linux and macOS.
```

## Graphics

| Asset | File | Spec |
| --- | --- | --- |
| App icon | `store/graphics/icon-512.png` | 512 × 512, opaque PNG |
| Feature graphic | `store/graphics/feature-graphic-1024x500.png` | 1024 × 500, opaque PNG |
| Phone screenshots | `store/graphics/screenshots/phone/*.png` | 1080 × 1920 (9:16) |

Both graphics are generated by `store/scripts/make_store_graphics.py`; the
screenshots by `integration_test/play_screenshots_test.dart`:

```sh
flutter test integration_test/play_screenshots_test.dart -d linux --dart-define=CHAOS_MEME_SOUNDS=false
```

The test writes RGBA PNGs; Play wants screenshots without alpha, so flatten
them before uploading:

```sh
python3 -I -c "from PIL import Image; import glob; [Image.open(f).convert('RGB').save(f) for f in glob.glob('store/graphics/screenshots/phone/*.png')]"
```
